## fix4 — agent-analyze done事件 + SuggestedQuestions浅色对比度 (2026-04-14)

### 问题A：聊天卡在"AI正在分析中"
**根因（推断+防御性修复）**：后端 `/api/ai/agent-analyze` 末帧确实发出 `event: done`（curl 验证通过），前端 `client.ts` 也有 `case 'done'`。但 SSE 解析的 try/catch 块用 `/* ignore parse errors */` 静默吞掉 JSON.parse 或 handler 内部抛出的任何错误——一旦 `onDone` handler 内任意调用抛错（如 Notification API、setFollowUps 边界），`setStreaming(false)` 不一定执行，UI 永久卡死。

**修复**：
1. `client.ts`：包裹 reader 主循环 try/finally，在通道关闭时强制触发新增的 `handlers.onClose?.()`；catch 改 console.warn 不再静默；记录 `doneEventSeen` 用于诊断。
2. `types/index.ts`：`SSEHandlers` 新增 `onClose?: () => void`。
3. `use-chat-stream.ts`：注册 `onClose` 兜底——若仍 isStreaming 则补落消息/清状态；`data?.follow_up_questions` 防御 nullish。

### 问题B：SuggestedQuestions 浅色文字看不清
**根因**：`suggested-questions.tsx:69` 写死 `text-white/70`——浅色模式下白底白字几近不可见。"继续探索"标签也用了 `text-muted-foreground` 对比度偏低。

**修复**：
- 问题文本 `text-white/70` → `text-foreground/85 dark:text-white/75`
- "继续探索"标签 → `text-foreground/70 dark:text-white/60`
- 满足 WCAG AA (≥4.5:1)
